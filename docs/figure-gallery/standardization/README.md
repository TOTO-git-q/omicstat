# P0-5 developer gallery

Eight synthetic examples, generated by the shared builders. These PNGs are
developer previews, not owner-approved or production-image evidence.
Each adjacent figure_spec.json records the image SHA256 and pending
per-family evidence review. No input data are patient records.

Runtime: isolated R 4.5.0, ggplot2 4.0.3, ragg 1.3.3, systemfonts 1.2.1.
Run `make_figure_gallery.R` in the pinned candidate to regenerate all suite
examples. The P0-5 fixtures are in `fig_fixtures_standardization.R`.

- km: survival curves, censor marks, log-rank annotation and aligned risk table
- hr: hazard-ratio intervals on a logarithmic axis
- time_roc: supplied time-dependent discrimination curves
- lasso: coefficient paths and an explicit selected penalty
- calibration: supplied predicted and observed event probabilities
- group_box: biological-unit points, box summaries and an explicit test bracket
- group_bar: biological-unit points and descriptive mean bars
- standard_curve: supplied 4PL curve and declared quantification range

LLOQ/ULOQ shading is not uncertainty. Technical wells are not biological
replicates. No builder fits a model or computes a test.
