How the suite differs from the workflow (read before using these numbers)
--------------------------------------------------------------------------
1. PRE-FILTER. The workflow's time-course section applies NO pre-filter to fission: the LRT runs
   on all 7,039 rows of data("fission"). The workflow's only pre-filter is in its airway section
   ("Pre-filtering the dataset", Rmd:746-769: count >= 10 in >= smallestGroupSize = 4 samples, the
   airway group size). The suite always requires an explicit --min-samples; its fission anchor run
   (smoke A1) uses --min-count 10 --min-samples 3 (3 = replicates per strain x minute cell) and
   keeps 6,205 rows. The workflow-identical run (smoke A0) uses --min-count 0 --min-samples 1,
   which keeps every row.
2. ALPHA. results(ddsTC) uses results()'s default alpha = 0.1 for independent filtering; the
   suite's default --alpha is 0.05 (A1). A0 passes --alpha 0.1.
3. REFERENCE LEVEL. data("fission") has strain levels wt, mut, so the workflow's last coefficient
   (printed log2 fold change) is strainmut.minute180. The suite orders levels by radix (mut, wt),
   so its last coefficient is strainwt.minute180, a different parameterization. baseMean, the LRT
   statistic, P and adjusted P are invariant; log2FoldChange/lfcSE are not the same coefficient.
