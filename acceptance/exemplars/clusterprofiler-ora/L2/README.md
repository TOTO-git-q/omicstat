# L2 -- clusterProfiler book (referenced, not copied)

The clusterProfiler vignette of the locked release (clusterProfiler 4.20.0, Bioconductor 3.23) only
points to the book "Biomedical Knowledge Mining using GOSemSim and clusterProfiler"
(https://yulab-smu.top/biomedical-knowledge-mining-book/). The book's source repository has no licence
file, so its text is not copied here: `manifest.tsv` pins the chapters used by this module to a commit
and records their sha256. The book follows the development versions (it also covers packages outside
the 3.23 release, e.g. `enrichit`); any default quoted from it is checked against the 3.23 Rd in
`../L1_bioc3.23/` before it enters the PACK.
