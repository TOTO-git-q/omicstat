# Troubleshooting

- OS_OWNER_DECISION_PENDING / OS_MISSING_PARAMETER: declare the missing scientific choice; do not copy tutorial examples as a default.
- OS_ECOSYSTEM_MIXED: use the matching front-end ecosystem throughout the chain. Python-to-R backend ecosystem labeling remains owner-pending.
- OS_BATCH_CORRECTED_INPUT: return to raw counts; corrected embeddings do not replace raw expression.
- OS_HANDOFF_MISMATCH: inspect object hashes, ordered genes, contract hash and the originating run; never edit the handoff to bypass a mismatch.
- OS_MISSING_LAYER / OS_MISSING_REDUCTION: name an existing assay/layer and run the matching upstream module first.
- OS_OUTPUT_EXISTS: select a fresh output directory; replay never overwrites an earlier run.
- OS_QC_BLOCKED: review qc/qc_results.csv; drafts are withheld while a blocker is present.
- OS_DEPENDENCY_MISSING: use the supplied locked image rather than installing a newer package into it.
