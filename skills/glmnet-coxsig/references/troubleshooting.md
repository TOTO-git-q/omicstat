# Failure handling

OS_MISSING_PACKAGE: exact OmicStat workup environment is unresolved. Do not install or substitute.
OS_INVALID_PARAMETER/OS_MISSING_PARAMETER: explicitly resolve required conditional scientific choices.
OS_CONFLICTING_PARAMETERS: validation cannot change planning, baseline, bootstrap or calibration policy.
OS_RESOURCE_LIMIT: B>2000 needs a separately validated larger-budget workflow; no silent cap/retry.
OS_INVALID_DESIGN: retain original identity/fold/event/variance support; do not invent independent draws.
OS_INVALID_RESULT: retain nonconvergence and failed native estimates. All-failed bootstrap is a hard failure.
OS_HANDOFF_MISMATCH: integrity and frozen workup must match; do not recalculate an expected digest to bypass it.
Missing R/Docker, real anchors, source/default capture, owner review and native image tests remain pending.
