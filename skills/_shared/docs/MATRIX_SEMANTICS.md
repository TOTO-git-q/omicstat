# Matrix values and panel compatibility

Load `fig_all.R`. Existing calls remain valid; they now export separate source,
analysis and display tables under `data`, plus a versioned
`definition.matrix_contract`. Exact binary64 values are retained in specs.

## Heatmaps

`os_heatmap` accepts `matrix_kind`, `row_entity`, `col_entity`, `quantity`, `unit`
and `source_unit`. Kinds other than distance are descriptive; a correlation kind
alone does not validate a scientific correlation matrix. Distance matrices must
be finite, nonnegative, symmetric and keyed identically on both axes, with exact
zero diagonal. Both axes reuse one tree/permutation and the palette begins at 0.

`normalization` supports identity and row/column variants of zscore, rms, max and
rank. Z-score uses sample SD; RMS is uncentered sqrt(sum(x^2)/(n-1)); max requires
nonnegative values; rank uses the full supplied axis and average ties. Source,
normalization parameters, derived values and unavailable states are retained.
Undefined constants, nonfinite references and zero divisors are never filled with 0.
Normalized units are dimensionless or rank; declare original units separately.

`missing_policy="error"` refuses clustering nonfinite values. Explicit
`"no_cluster"` leaves affected axes unclustered; a validated source hclust may
instead supply their order. The figure layer does not impute or refit a model.
`row_hclust`/`col_hclust` accept existing dist/hclust objects. Supplied rotations
must be valid tree leaf rotations and retain merges/heights. Arbitrary `row_order`
or `col_order` ID permutations require clustering to be disabled.

A time axis uses `row_axis_role`/`col_axis_role="time"` and named finite numeric
axis keys. It defaults to chronological order. Explicit clustering warns and
records the original keys. Design axes also default to supplied order.
`os_align_matrices` constructs a shared ID union with explicit unmeasured gaps;
these do not inflate original missing counts.

`clip`, explicit colour `limits` and `display_mask_gt` affect only display values.
Masking is strictly greater than the threshold; `display_mask_abs=TRUE` opts into
absolute-value masking. Raw/analysis values and trees are unchanged. Actual
colourbar breaks, clipping counts and source/display states are recorded.

`cell_metadata` is a full long table keyed by row_id and col_id. It contains
value/state when supplied, test_metric, threshold and fit_id; unknown provenance
must be labelled unknown. It cannot replace raw values. Nonsignificance needs a
P/FDR metric; not_credible needs a posterior rule. Missing, infinite, unmeasured,
reference, non-significant, not-credible and failed states have distinct visible
symbols. The request bridge can provide states through this table.

## Bulk adapters

`os_sample_distance` accepts annotation_cols, distance_source, preprocessing,
metric, linkage, distance_unit and show_sample_labels. Preprocessing is explicitly
unknown/blind/design-aware. It never infers branch support or general superiority.

`os_top_heatmap` retains adjusted-P selection and stable feature IDs. `col_unit`
is sample or condition_average; condition averages require an explicit
aggregation_order of zscore_then_mean or mean_then_zscore. Source samples and
replicate counts remain separate from displayed column count. Independent units
are unknown unless established elsewhere. Selected features are not described as
unsupervised whole-transcriptome validation.

## Composition

`os_panel_contract` attaches actual guide/axis mappings and panel population
context. For ggplots, declared mappings, limits and ticks are checked against
rendered scales. Nested plots use contracts generated by their builder.

`os_compose(collect_guides=TRUE)` collects only exactly compatible, known guide
contracts. Conflicting same-entity mappings fail; reused colours for different
entities or missing/unknown contracts keep local guides and issue a warning.
Nested compatible heatmaps receive one actual external legend, rather than
claiming collection while retaining duplicate wrapped legends.

`shared_axes` is none/x/y/both; shared axes require the same known quantity, unit,
transformation, limits and ticks. `linked_rows`/`linked_cols` require identical
explicit ID order, including unavailable slots. Independent scales and object
orders are labelled visibly. No panel's cohort, endpoint, horizon or validation
scope is silently promoted to the full composite.

## Python request bridge

`frame(table, row_id="sample_id")` writes a checksum-protected identity column.
The R reader makes it the row-name index and removes it from annotation tracks.
IDs must be unique nonempty strings. All numeric integers must round-trip exactly
through binary64, while explicitly typed integers must fit R's non-missing 32-bit
integer range. Matrices reject duplicate/empty axes. Scientific estimates are
still supplied data, never inferred by the renderer.
