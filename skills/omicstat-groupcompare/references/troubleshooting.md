# Troubleshooting
OS_INVALID_DESIGN: verify biological identities, complete pairs and prespecified method compatibility.
OS_MISSING_PARAMETER: provide the scientific declaration rather than guessing a default.
OS_CONFLICTING_PARAMETERS: remove irrelevant comparisons/rank options or declare the intended test.
OS_MODULE_UNSEALED: use development-mode only for candidate testing; this does not grant acceptance.
Constant observations can make a test undefined. Do not add noise or drop observations to force a p-value.

OS_GPC_INVALID_SPEC: check explicit fixed grid, reference, minimum >=10, bootstrap count >=200 and finite
fraction >=.95. Do not relax these thresholds to force a figure or confidence interval.
OS_CONFLICTING_PARAMETERS also refuses distribution controls in the hypothesis-test branch and vice versa.
For source small-cell/tail/increment or degenerate-bootstrap findings, retain missing values and labels.
Source quantile intervals are not simultaneous bands. Whole-withheld pages intentionally have no plot.
Use a fresh evidence directory after any failed run; preserve the prior logs. Missing R4.6.1, jsonschema,
installed native packages or owner source receipts must remain explicit blockers, never synthetic substitutes.
