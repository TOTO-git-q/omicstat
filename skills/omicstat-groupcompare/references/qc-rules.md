# QC rules
| Rule | Severity | Trigger | Action |
|---|---|---|---|
| GPC-01 | blocker | always, candidate | Obtain scientific, exec and visual review |
| GPC-02 | warning | technical rows aggregated | Inspect biological_units and declared IDs |
| GPC-03 | warning | family >1, adjust none | Review exploratory multiplicity declaration |
Input errors are typed refusals, not post-hoc filters. No silent NA removal or pair deletion.

| GPC-04 | warning | source advisory requested | Report heuristic scope alongside the actual prespecified test |
| GPC-05 | warning | independent distribution effects | Report pointwise coverage and no hypothesis family |
Mapped OS_GPC source findings retain their blocking status. Small-cell/effective-n/tail/increment and
bootstrap failures remain visible without disclosing raw identities, small counts or invented estimates.
Wholly suppressed pages are recorded as withheld_no_released_effect, never replaced with zero plots.
