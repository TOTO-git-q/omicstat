# QC rules

| Rule | Check | Severity | Source |
|---|---|---|---|
| LD-01 | fewer than three replicates in a compared group | warning | ENGINEERING_PLAN 4.5 |
| LD-02 | fewer than 100 tested features | warning | PACK C; ENGINEERING_PLAN 4.5 |
| LD-03 | all adjusted P values unavailable | error | ENGINEERING_PLAN 4.5 |
| LD-04 | nonfinite log2 fold change | error | ENGINEERING_PLAN 4.5 |
| LD-05 | all tested features significant | warning | ENGINEERING_PLAN 4.5 |

Pre-fit blockers require repeated, described blocks, full-rank design and at least two residual degrees of freedom (PACK S1 P-2).
