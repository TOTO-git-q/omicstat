# QC rules
- MS-00: blocker, numerical acceptance pending. Always active in this draft. Cannot be bypassed by a CLI flag.
- MS-01: warning, only two biological replicates in a group; suite convention, not an asserted package minimum.
- MS-02: blocker, no estimable adjusted P values.
- MS-03: blocker, nonfinite tested effect.
- MS-04: blocker, any MSstats engine issue (inactive for proDA).
Input identity, scale and design errors fail before model fitting. Warnings are captured, never silently suppressed. All excluded proteins remain represented. These safety guards do not establish calibration or manuscript readiness.
