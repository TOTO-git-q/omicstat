# Parameters

Defaults follow the locked function formals. Study choices require explicit flags (sol61_common policy).

| Flag | Default | Allowed | Why |
|---|---|---|---|
| --input | none | path | QC-complete SCE RDS |
| --from-run | none | path | scater-qc handoff directory |
| --outdir | required | path | output directory |
| --spec | none | path | replay resolved spec |
| --n-hvg | required | int | explicit number of biological HVGs; OSCA examples use 2000 |
| --n-pcs | required | int | explicit PCA rank; inspect elbow/variance before selecting |
| --graph-k | required | int | graph neighbours; locked NNGraphParam example/default 10 |
| --cluster-method | walktrap | enum | bluster graph clustering algorithm |
| --quick-method | igraph | enum | quickCluster preliminary clustering method |
| --quick-min-size | 100 | int | quickCluster minimum cluster size |
| --pool-sizes | 21,26,31,36,41,46,51,56,61,66,71,76,81,86,91,96,101 | string | comma-separated deconvolution pool sizes |
| --pseudo-count | 1 | num | logNormCounts pseudocount |
| --block-col | none | string | optional variance-model blocking column |
| --sample-col | none | string | sample annotation for UMAP |
| --batch-col | none | string | batch annotation for UMAP |
| --umap-neighbors | required | int | UMAP neighbours; locked default/example 15 |
| --umap-min-dist | 0.01 | num | locked uwot minimum distance |
| --quickcluster-args | none | path | supplementary quickCluster arguments in named JSON |
| --pool-args | none | path | supplementary computeSumFactors arguments in named JSON |
| --lognorm-args | none | path | supplementary logNormCounts arguments in named JSON |
| --variance-args | none | path | supplementary modelGeneVar arguments in named JSON |
| --hvg-args | none | path | supplementary getTopHVGs arguments in named JSON |
| --pca-args | none | path | supplementary runPCA arguments in named JSON |
| --graph-args | none | path | supplementary NNGraphParam including cluster.args e.g. resolution in named JSON |
| --umap-args | none | path | supplementary runUMAP/uwot arguments in named JSON |
| --seed | 100 | int | scran vignette explicit seed |
| --journal | nature | enum | figure preset |

Every analysis call and defining S4 method default is recorded in scripts/calls_registry.json, generated by reading the locked container. Empty function defaults are required arguments. Generic formals and method formals are recorded separately. Aliases are not used. Threads: one; BiocParallel: SerialParam.
