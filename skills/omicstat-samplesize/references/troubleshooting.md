# Troubleshooting

OS_MISSING_PACKAGE means the exact independently provisioned OmicStat dependency
is absent. Do not install from MedStat, silently pick another version or substitute
an estimator. OS_CONVERGENCE retains the native failure message or the explicit
allocation search ceiling. OS_MISSING_PARAMETER and OS_CONFLICTING_PARAMETERS
require resolving the declared design, not selecting defaults. OS_INVALID_DESIGN
rejects pseudoreplication and direction/design conflicts. OS_CONTRACT_MISMATCH
requires the original StudyContract bytes. OS_MODULE_UNSEALED without
--development-mode is intentional. A passed contract plot is not real owner evidence.
