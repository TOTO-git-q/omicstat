# Reporting fields

Report the independent biological unit and design, raw planning effect and its
source/rationale, native engine, alpha, sidedness/direction, target power, planned
allocation, analyzable n/event count and separately attrition-adjusted recruitment.
Report the technical measurement budget separately and state that it does not
increase biological n. Report event probability when converting log-rank events
to N. Do not print an estimated effect/CI from the planning assumption, claim native
acceptance before execution, or describe the synthetic contract plot as real data.
