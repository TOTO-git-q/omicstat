# immunedeconv-infiltration
Wrap the locked immunedeconv 2.1.4 official workflows and preserve their native result tibble. Choose --method explicitly: quantiseq, mcp_counter, epic, xcell, timer, abis, consensus_tme, estimate, cibersort or cibersort_abs. See references/options.md for each method's licence, data source, interpretation and scale.

Use --input expression.csv or --from-run upstream, --upstream-object expression_matrix, --input-scale TPM, --outdir run. Human HGNC gene symbols are required. TPM must be linear, nonnegative and supported by upstream provenance; sample totals above 1,010,000, counts/log/VST and corrected matrices are refused. MCP-counter also accepts --input-scale log2TPM meaning log2(TPM+1): the native transform is explicitly selected from this declaration. Arrays remain unsupported: --arrays false. No scale is inferred from expression magnitudes.

EPIC requires --accept-licence epic: academic non-commercial use, no redistribution/sublicensing, agreed users only, and attribution. Its inherited private-image data must remain private. Both CIBERSORT methods require --accept-licence cibersort, --cibersort-source and --cibersort-matrix: licensed source and LM22 are supplied by the user and never bundled. Missing acknowledgement yields OS_LICENCE_REQUIRED; missing files yield OS_REFDATA_MISSING. Unknown methods yield OS_METHOD_UNAVAILABLE.

TIMER and ConsensusTME require --indications: comma separated documented cancer types, one per sample in input order; no automatic choice. --tumor true|false, --scale-mrna true|false and --rmgenes retain native quantiseq/EPIC behaviour. xCell exposes --expected-cell-types (NULL means all), --xcell-threads (1 explicit deterministic worker), --xcell-alpha (0.5 native), --xcell-scale true|false (true native). --consensus-stat-method ssgsea names the framework fixed by the top-level wrapper. --seed 20260925, --journal nature|cell|science|generic and --spec support reproducible runs.

Outputs: infiltration.rds, native infiltration.csv, expression.csv handoff, suite heatmap, actual-option/licence Methods, results.json, provenance with method/unit/licence acknowledgement. quanTIseq and EPIC estimate cell fractions; CIBERSORT estimates relative signature fractions. ABIS yields estimated percentages, potentially negative. MCP-counter, xCell, TIMER, ConsensusTME and CIBERSORT absolute produce method-specific scores: compare the same cell type across samples, never treat them as fractions or compare magnitudes across cell types. ESTIMATE returns three scores and a separate purity estimate. Score heatmaps use within-row z-scores for display, leaving native tables unchanged. No group inference or clinical interpretation is performed.

## 待裁决
Before choosing --method, --input-scale, --indications, --tumor, --arrays, --scale-mrna, --rmgenes, --expected-cell-types, --xcell-alpha or --xcell-scale, call reference_advise(module="immunedeconv-infiltration", ...) and reference_search. If no curated evidence applies, show the official Racle example (human melanoma TPM, quantiseq, tumor=true, arrays=false, scale_mrna=true) and ask the user. Popularity does not set defaults. Methods requiring unavailable/unverified data remain refused. CIBERSORT computation remains conditional on real licensed files; no successful replay is claimed without them. S2 awaits independent S3.

`--method-args` accepts offline named JSON arguments for the selected native wrapper; `--cibersort-abs-method sig.score|no.sumto1` binds the native absolute score control. JSON abs_method overrides the dedicated flag. Consult `reference_advise` and `reference_search` before choosing these options; ask the user when evidence is absent. CIBERSORT still requires user-supplied licensed source, signature and acknowledgement. Interface smoke stubs are synthetic and never a licensed CIBERSORT execution claim.
