# Methods template

Slingshot {version} inferred lineages and pseudotime on the supplied {reduced_dim} embedding with the recorded root/curve controls. When requested, tradeSeq {version} fitGAM and associationTest used the recorded knot count, covariates and test settings. RNG version and seed were recorded.

The engine fills its short Methods output from actual native function arguments, package versions and seed; all result-affecting options are recorded in the same output and provenance.
