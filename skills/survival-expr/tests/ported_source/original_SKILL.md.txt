# survival-expr

## When to use / when not
Use for continuous prespecified gene expression and one right-censored event per subject.
Clinical-only models belong to medstat. No competing risks, recurrent events, left truncation,
interval censoring, repeated biological samples, automatic gene selection or diagnostic cutpoint claims.

## Input requirements
An integrity-verified --from-run expression_matrix handoff is mandatory. Raw matrix paths cannot
replace it. Candidate, display-only and batch-corrected inputs are refused. Clinical CSV must match
all matrix sample IDs exactly; --unit-col preserves string identities and never derives n from rows.
Time must be positive and event explicitly 0=censored,1=event. No automatic recoding or case deletion.
Numeric covariates only; categorical contrasts must be explicitly encoded upstream. Gene identifiers
are exact; use the offline idmap snapshot/report upstream when mapping is needed. No online lookup. Maximum 100 tested genes and 5000 subjects; optimal search allows at most 256 unique thresholds and never silently subsamples.
Declare normalized expression scale, per-gene scaling, ties, minimum events, iterations/tolerance,
PH transform/threshold, planned gene family and p adjustment, marginal CI and study contract.

## Run
Prepare tests/prepare_acceptance.py with a new fixture directory, then use the complete command in
tests/acceptance.json with --development-mode. All scientific choices are required.
The numerical fixture uses clinical age as AGE_PROXY solely to reproduce published Cox values.
It is not evidence for a real gene-survival association. A real limma-array producer tests chaining.

## What gets produced
Per-gene HR/Wald tables, all coefficient estimates, PH tests, scaling parameters, KM curves,
aligned risk counts, subject/group memberships, full exploratory cutpoint search if requested,
two scientific PNG/PDF/spec figures, candidate typed models, QC, methods and provenance.

## Reading the results
Cox tests continuous expression, not dichotomized groups. Each gene has its own covariate-adjusted
model. P adjustment covers the declared gene family; CI is marginal, not simultaneous.
KM is an unadjusted display for one explicitly chosen gene. Low means expression <= cutoff.
Median is outcome-independent; prespecified needs a numeric cutpoint on the supplied expression
scale. Optimal requires --exploratory and --min-group-fraction; its logrank p is withheld and
both result metadata and figure caption label the search exploratory. No corrected search p is invented.
PH diagnostics never silently remove genes. At-risk counts include subjects observed at the time.

## When a QC rule fires
SRV-01 blocks candidate publication; SRV-02 blocks confirmatory optimized-cutpoint interpretation;
SRV-03 requests review of PH assumptions; SRV-04 flags an unadjusted multiple-gene family.
Undefined endpoint KM intervals stay missing in tables; the figure omits interval bounds if needed.

## Known limitations
No categorical-covariate parser, interactions, robust clustered SE, competing risks or missing-data
imputation. No clinical-only pathway. Owner scientific/visual review and production exec pending.
Cutpoint search is exploratory, cannot justify a clinical biomarker threshold. No accepted registration.
