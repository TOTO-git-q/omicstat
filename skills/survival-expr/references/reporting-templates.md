# Reporting

Always state actual dataset/version, original biological n, events, expression processing and
scale, prespecified genes/covariates, cutoff rule/value and analysis mode. Every extension figure
carries dataset_name. Synthetic software inputs must be labelled synthetic, never owner evidence.

For nonph, report transform(s), source fixed P0.05, original ph-alpha, declared magnitude and
reason/NA counts. State that diagnostics do not choose models or filter genes. For piecewise,
report declared cuts, (start,stop] endpoint rule, independent original n, split rows, period risk
and event counts, finite/non-estimable periods, native defaults/version, adjustment and family.
Report original continuous-model controls separately; do not attribute them to source-native fits.

For CIF, report nominated cause, every status code, original n, target/competing/censored counts,
all-outcome competing percentage, display split, bounded timepoints and AJ point estimates only.
No CI, Gray, adjusted association or causal claim is supported. Initial-state risk counts use
original subjects immediately before t. Never relabel the diagnostic 1-KM column as incidence.

Do not publish row-level inputs, memberships, individual expression values or fitted subject
objects in owner evidence. Original Cox runs include such artifacts locally; any real authorized
executor anchor must export only approved aggregates and verified source/data/code bindings.
