# Methods template

Cell counts were summed by cluster and biological sample using muscat {version} aggregateData, following prepSCE. pbDS used the recorded method, design, contrast/coefficient, minimum-cell and filtering choices. Complete native per-cluster results retain within-cluster and global adjusted P-values. Samples were the units of replication.

The engine fills its short Methods output from actual native function arguments, package versions and seed; all result-affecting options are recorded in the same output and provenance.
