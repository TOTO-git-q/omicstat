# Reporting templates

```template methods
Cells were annotated using SingleR v{singler_version} against {reference} ({reference_version}; species {species}; SHA-256 {reference_sha256}), with {unit} as the annotation unit and {test_role} as the test assay. Reference markers used de.method={de_method}, de.n={de_n}; quantile={quantile}, fine.tune={fine_tune}, tune.thresh={tune_thresh}, aggr.ref={aggr_ref}. Pruning used nmads={nmads}, min.diff.med={min_diff_med} and min.diff.next={min_diff_next}. Ambiguous assignments were retained as unassigned. The recorded seed was {seed}. Actual resolved native parameters: {resolved_native}.
```

```template results
Of {n_cells} cells, {n_assigned} retained pruned labels and {n_unassigned} were unassigned. Full label scores and cluster-by-label cell counts are supplied as diagnostic tables; annotation does not establish differential expression or biological ground truth.
```

Placeholders are populated from the result object and resolved arguments; reference hash is computed from the supplied file. Figure captions are generated by the shared builders.
