# CLI contract

The entry script is the authority for types and accepted values; --help renders the same os_arg_spec. Scientific input/normalization choices are explicit.

- --matrix
- --samples
- --sample-col
- --bio-col
- --condition
- --input-scale
- --zero-policy
- --normalization
- --outdir
- --spec
- --reference
- --target
- --feature-id-type
- --alpha
- --label-n
- --seed
- --journal

No arbitrary R formula or expression is accepted. --spec replays canonical arguments; choose a new --outdir. Inputs are local files; no runtime download or package installation is implemented.
