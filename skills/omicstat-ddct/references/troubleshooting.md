# Troubleshooting
OS_INVALID_INPUT: resolve missing/undetermined/over-limit Ct scientifically, never replace by Ct-max silently.
OS_INVALID_DESIGN: verify complete gene/well/unit identities, assay declaration and biological n.
OS_MODULE_UNSEALED: candidate-only execution does not grant accepted publication status.
Same-well layout requires the same well identifier for target and reference; separate wells must not be paired by row.
