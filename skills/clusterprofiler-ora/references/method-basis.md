# Method basis — clusterprofiler-ora

- Frozen owner decisions: `acceptance/exemplars/clusterprofiler-ora/PACK.md` S1 appendix P-1 to P-3 (2026-09-27).
- Locked package: clusterProfiler 4.20.0, `L1_bioc3.23/clusterProfiler/Rd/enrichGO.Rd` for ontology, universe, set size, adjusted P, q-value and pool; `Rd/simplify.Rd` for optional semantic reduction.
- GO annotation: org.Hs.eg.db 3.23.1 and GO.db as installed in `omicstat-r:2026.09.1`; registry key `go_annotation`. The registry lacks a container asset sha256 and licensing evidence, which remains an owner item.
- Testing families (S4, clusterProfiler 4.20.0 source read in the locked container): `enrichGO(ont = "ALL", pool = FALSE)` calls `enrichGO` once per ontology and binds the rows, so BP, CC and MF each have their own effective input (GeneRatio denominator), background (BgRatio denominator), BH adjustment and q-values; `pool = TRUE` builds one GO collection of all three ontologies (one denominator pair, one BH family). The engine verifies per family that the denominators are unique and that p.adjust equals BH over that family, and refuses otherwise. It never substitutes a union background.
- Simplify relation: `clusterProfiler::simplify` returns only the kept terms. The engine captures the Wang similarity matrices that simplify itself computes and replays its selection loop (`simplify_internal`: groups of similarity > 0.7 around each term in result order; smallest p.adjust kept, ties by most GO ancestors; ALL per ontology via `simplify_ALL`) to list every merged term with its representative; the reconstructed kept set must equal the package output.
- Symbols: `enrichit::EXTID2NAME`, the mapping inside `setReadable` (first symbol per ID; unmapped IDs keep their ID).
- Enrichment uses a hypergeometric test on GO terms with overlap, followed by BH adjustment. The test does not test zero-overlap or unannotated sets (enrichit 0.2.1 NEWS). The supplied universe is the selection-eligible population, not all genes in an annotation package.
