Network type (owner adjudication 2026-10-11, PACK D-WG5): `--network-type` is required. The package author recommends a signed variety (Langfelder, "Signed or unsigned: which network type is preferable?", 2018-11-25, https://peterlangfelder.com/2018/11/25/signed-or-unsigned-which-network-type-is-preferable/) and describes the unsigned `blockwiseModules` default as retained for historical compatibility; the pinned tutorial uses unsigned. The corpus has no majority (signed 9 of 23, 14 not reported).
