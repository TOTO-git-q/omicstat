# Parameters

Defaults follow the locked function formals. Study choices require explicit flags (sol61_common policy).

| Flag | Default | Allowed | Why |
|---|---|---|---|
| --input | none | path | SCE RDS with raw counts |
| --from-run | none | path | upstream SCE handoff |
| --outdir | required | path | output directory |
| --spec | none | path | replay resolved spec |
| --mt-genes | required | path | one mitochondrial feature ID per line |
| --species | required | string | declared species |
| --id-type | required | string | declared feature ID namespace |
| --qc-mode | required | enum | explicit filtering policy |
| --nmads | none | num | required for mad mode; vignette example 3 |
| --min-counts | none | num | fixed-mode minimum total counts |
| --min-features | none | int | fixed-mode minimum detected genes |
| --max-mito | none | num | fixed-mode maximum mitochondrial percent |
| --batch-col | none | string | metadata column for per-batch MAD estimates |
| --metrics-args | none | path | JSON named supplementary perCellQCMetrics arguments |
| --filter-args | none | path | JSON named supplementary perCellQCFilters arguments; explicit thresholds take precedence |
| --seed | 20260925 | int | recorded random seed |
| --journal | nature | enum | figure preset |

Every analysis call and defining S4 method default is recorded in scripts/calls_registry.json, generated by reading the locked container. Empty function defaults are required arguments. Generic formals and method formals are recorded separately. Aliases are not used. Threads: one; BiocParallel: SerialParam.
